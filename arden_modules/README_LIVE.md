# Arden Live — живые сигналы в Telegram

Раннер следит за рынком круглосуточно, находит сетапы Power of Three и присылает
готовый план сделки в Telegram. Плюс локальный дашборд с графиком и уровнями.

---

## Запуск за три шага

### 1. Создать бота и узнать id чата
- В Telegram открой **@BotFather** → `/newbot` → получишь **токен** вида `8123456789:AAF...`
- Открой **@userinfobot** → пришлёт твой **id чата** (число, например `501234567`)
- Напиши своему боту `/start` — иначе он не сможет тебе писать

### 2. Вписать в настройки
Запусти `START.bat` — рядом появится `config.json`. Открой его блокнотом и заполни:
```json
"telegram": {
  "bot_token": "8123456789:AAF...",
  "admin_chat_id": "501234567"
}
```

### 3. Запустить
Снова `START.bat`. Всё — раннер работает и **сам прописался в автозагрузку Windows**.
После перезагрузки компьютера стартует автоматически, окно скрыто.

Проверить связь с ботом: `START.bat --test-telegram`

## Что приходит в Telegram

```
Стратегия Арденского
НОВЫЙ СЕТАП — выставить лимит

BTC/USDT · 12h · 🔺 LONG

вход: 77 531.56
сл:   76 264.00  (−1.63%)
тп1:  79 432.90  (+2.45%) — 1.5R, закрыть 33%
тп2:  81 334.24  (+4.90%) — 3.0R, закрыть 67%

После тп1 — стоп в безубыток.
Объём: риск 0.5% счёта ÷ 1.63% = 31% депозита.

слом за 3 бар(а), импульс 3.6 ATR · цена 81 270.37
```

Два типа сообщений:
- **НОВЫЙ СЕТАП** — структура сломана, ставь лимитный ордер на цену входа
- **ВХОД ИСПОЛНЕН** — цена дошла до лимитника, позиция должна быть открыта

Повторов не будет: каждый сетап отправляется один раз (запоминается в `live_state.json`).

## Дашборд

Файл `dashboard.html` обновляется каждый проход. Открой его в браузере —
он сам перезагружается раз в 3 минуты.

Показывает: результаты бэктеста, график свечей с линиями входа/стопа/целей,
карточки активных сигналов, разбивку по таймфреймам и годам.

---

## Как торговать сигнал

1. Пришёл сигнал — выставить **лимитный ордер** на цену входа, плюс стоп и тейки.
   Вход **не по рынку**: сетап отрабатывает именно на коррекции.
2. Если за 10 баров лимит не исполнился — снять ордер, сетап устарел.
3. На первой цели (1.5R) закрыть **треть** позиции и перевести стоп в **безубыток**.
4. Остаток держать до второй цели (3R).
5. Одновременно держать **не более 10** позиций.

Объём считается автоматически: `риск% ÷ размер стопа%`.
При риске 0.5% и стопе 1.63% это 31% депозита без плеча.

## Настройки (config.json)

| параметр | по умолчанию | что делает |
|---|---|---|
| `symbols` | BTC, ETH, SOL | какие пары отслеживать |
| `timeframes` | 2h, 4h, 6h, 12h | таймфреймы (проверенный портфель) |
| `ote` | 0.79 | глубина входа в коррекцию |
| `min_stop_percent` | 0.7 | сетапы с более тугим стопом пропускаются |
| `risk_percent_per_trade` | 0.5 | риск счёта на сделку |
| `tp1_R` / `tp2_R` | 1.5 / 3.0 | цели в единицах риска |
| `poll_seconds` | 120 | как часто проверять рынок |
| `notify_on_fill` | true | слать ли уведомление об исполнении входа |
| `autostart` | true | прописывать ли себя в автозагрузку |

## Команды

```
START.bat                      обычный запуск
START.bat --once               один проход и выход (проверка)
START.bat --test-telegram      проверить связь с ботом
START.bat --no-autostart       запуск без прописывания в автозагрузку
STOP_AUTOSTART.bat             убрать из автозагрузки
```

**Где живёт автозапуск:** ярлык `ArdenLive.vbs` в папке
`%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup`.
Его можно просто удалить вручную — это обычный файл, прав администратора не требует.

**Логи:** `arden_live.log` рядом с раннером.

| метрика | значение |
|---|---|
| сделок | 1095 (123 в год) |

| на сделку | +0.491R (95% ДИ 0.395…0.581) |
| профит-фактор | 2.01 |
| прибыльных | 55% |
| при риске 0.5% | **+34.5% годовых**, просадка −8.4% |
| при риске 1.0% | +79.4% годовых, просадка −16.4% |
| макс. позиций разом | 10 (пик 5% счёта под риском) |

Обучающая выборка (до 2024) дала +0.482R, проверочная (с 2024) — **+0.507R**.
Прибыльна каждый год, включая боковой 2025 (+0.362R) и медвежий 2022 (+0.398R).

**Честно:** это результат тестирования на истории, а не гарантия. Худшая серия
убытков подряд — 15. Реальное исполнение лимитника на выносе может отличаться
от модели. Комиссия учтена как 0.10% туда-обратно; стратегия остаётся
прибыльной вплоть до 0.50%.
